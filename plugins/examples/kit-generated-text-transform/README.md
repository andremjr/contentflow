# ContentFlow Kit Text Demo

Plugin gerado pelo kit oficial do ContentFlow OS usando a API pública v1.

## Desenvolvimento

Na raiz do ContentFlow OS, substitua `<pasta-do-plugin>` pela pasta deste plugin:

```powershell
npm run plugin:kit -- validate <pasta-do-plugin>
npm run plugin:kit -- test-contract <pasta-do-plugin>
npm run plugin:kit -- test-sandbox <pasta-do-plugin>
npm run plugin:kit -- report <pasta-do-plugin>
```

Credenciais declaradas: nenhuma. Não grave valores secretos no manifesto.

Política de dados: não envia dados a terceiros.
