# Plugins de referência

Esta pasta contém plugins independentes disponibilizados como implementações iniciais, exemplos funcionais e material de demonstração do ecossistema ContentFlow.

Eles não fazem parte do núcleo, não são carregados automaticamente e não recebem confiança especial. Cada pacote precisa ser instalado ou conectado pelo usuário, passa pela mesma validação, consentimento e sandbox e pode ser removido sem afetar o ContentFlow.

A publicação aqui não representa promessa de suporte, manutenção contínua, compatibilidade futura nem disponibilidade dos serviços de terceiros. Cada manifesto é a fonte da identidade, versão, capacidades, permissões e política de dados do respectivo pacote. IDs legados são preservados somente para compatibilidade com Métodos e instalações existentes.

Para criar seu próprio plugin, use o [`Plugin Kit`](../../plugin-kit/) e comece pelo [`guia rápido`](../../docs/quickstart.md). O contrato normativo está em [`protocol.md`](../../docs/protocol.md), os controles obrigatórios em [`security.md`](../../docs/security.md) e as responsabilidades de distribuição em [`distribution.md`](../../docs/distribution.md).
