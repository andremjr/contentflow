# Plugins

- [`reference`](reference/) é a pasta histórica que reúne a coleção atual de pacotes completos, sem vínculo com o ciclo de release do núcleo e sem tratamento privilegiado no aplicativo.
- [`examples`](examples/) reúne implementações mínimas para aprender e testar o protocolo.

Plugins de terceiros não precisam ser adicionados a este repositório. Eles podem viver em repositórios próprios, usar licença própria e ser instalados por pasta ou conectados como pasta ao vivo.

Não existe distinção de instalação entre plugins pelo autor do ContentFlow e plugins de outros
participantes da comunidade. Todos passam pelo mesmo protocolo, validação, consentimento, ativação,
sandbox, atualização e remoção.
