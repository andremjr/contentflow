# ContentFlow v0.4.18

## Correções no aplicativo

- Preserva imagens da tentativa reprovada para que plugins compatíveis possam anexá-las ao abrir outra conversa.
- Aceita caminhos de instalação de plugins com ou sem aspas.
- Numera novas entradas manuais para evitar variáveis padrão repetidas no bloco. Entradas antigas não são renomeadas automaticamente.
- Reduz o tamanho da prévia de layouts nos cartões compactos do operador humano.
- Evita o aviso de ID duplicado quando uma pasta de desenvolvimento substitui intencionalmente a cópia instalada do mesmo plugin.

## ChatGPT Browser Studio 1.0.6

- Reanexa imagens da tentativa reprovada ao abrir outra conversa, preservando as observações da correção.
- Aguarda os indicadores de upload e a disponibilidade do botão antes de enviar o prompt.
- Distingue imagens das respostas do assistente dos anexos enviados pelo usuário, para não devolver a referência antiga como resultado novo.
- Coleta múltiplas imagens da resposta, sem limite fixo de duas, e reconhece o controle de geração em português.

**Atualize também o plugin:** ele é distribuído separadamente do aplicativo. Para receber várias imagens no Método, conecte a porta `images` a uma saída do tipo `files`; a porta `image` continua entregando somente a primeira imagem.

## Validação

- Teste real no Electron com três imagens disponíveis para seleção humana, concluído pelo usuário após ajustar a configuração do Método.
- Testes manuais de reprovação, reanexo, espera do upload e captura da imagem revisada, seguidos da autorização do usuário para esta release.
- Testes automatizados de múltiplas imagens, distinção entre anexo e resultado, upload lento, cancelamento e timeout. Não foi realizado teste real com quatro ou cinco imagens nesta validação.

## Downloads

Use o instalador `ContentFlow-V0-0.4.18-x64-Setup.exe` ou a versão portátil `ContentFlow-V0-0.4.18-x64-Portable.exe`. Os dados locais permanecem na pasta de dados do ContentFlow. O plugin atualizado está no pacote `ContentFlow-Plugin-chatgpt-browser-studio.zip`.
