# ContentFlow 1.3.4

Nas páginas de Métodos e Plugins, **Explorar ecossistema** abre a vitrine do GitHub Pages com a categoria correspondente selecionada. O botão **Baixar plugins** também aponta para essa vitrine. O novo texto possui versões em português do Brasil, inglês e espanhol.

O site continua consultando os catálogos dos repositórios independentes. Instalação e atualização dentro do aplicativo continuam usando esses mesmos catálogos; plugins e Métodos não recebem novas versões nesta release.

Validação: links conferidos nas duas páginas do preview, rótulos e destinos verificados nas três línguas, checagem TypeScript e montagem local. A seleção de categoria também é conferida no site público. Esta mudança não altera execução, perfis ou persistência.

Publicação local e direta pela API do GitHub, sem GitHub Actions.
