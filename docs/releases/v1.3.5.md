# ContentFlow 1.3.5

- Migração assistida: após atualizar os plugins, o agente conectado por MCP pode consultar o plano, validar e propor Métodos compatíveis durante o bloqueio de migração. As propostas são aplicadas junto da migração confirmada, com backup verificável, preservação de históricos e proteção do trabalho iniciado. Propostas desatualizadas exigem nova revisão.
- Biblioteca Estratégica: itens das coleções podem ser editados pelo formulário existente. A alteração preserva identidade, Canal, coleção e data de criação; itens reservados continuam protegidos.
- Editor de Métodos: **Apagar Método** remove toda a definição do Processo após confirmação. A ação respeita dependências e trabalho iniciado, sem excluir o Processo Universal, a Biblioteca ou resultados concluídos.
- Textos das novas interfaces em português do Brasil, inglês e espanhol. O guia de migração e as skills distribuídas acompanham a versão atual.

Plugins e Métodos do catálogo independente mantêm suas versões. Montagem local e publicação direta pela API do GitHub, sem GitHub Actions.
