# ContentFlow v0.5.0

## Editor de Métodos

- Adiciona **Testar somente este bloco**: executa a configuração atual do bloco sem criar Projeto, Execução, Entrega ou Histórico do Canal.
- O teste solicita valores fictícios para cada entrada necessária, incluindo dados de Projeto usados pelo prompt, em vez de reutilizar dados reais.
- Resultados e arquivos do teste são temporários, removidos ao fechar o editor e expirados automaticamente.
- Chamadas ao provedor permanecem reais e o editor avisa quando podem consumir cota, criar conversa ou gerar mídia.
- Entradas e variáveis de prompt passam a ter vínculo bidirecional: criar uma entrada insere sua variável, renomear atualiza o token e remover qualquer lado remove o outro.

## Navegador e Browser Bridge

- A execução normal continua usando a janela dedicada minimizada/em background.
- O teste manual de bloco mantém o navegador visível para oferecer retorno visual durante a configuração.
- A Bridge e os plugins de navegador recebem melhorias de reconexão, cancelamento, isolamento de sessão e confiabilidade de comandos.

## Validação

- `npm run release:verify` aprovado após a autorização de release.
- 137 testes dos plugins de navegador, 9 cenários E2E e 2 cenários reais no Electron aprovados.
- Auditoria de dependências: nenhuma vulnerabilidade conhecida.

## Downloads

Use o instalador `ContentFlow-V0-0.5.0-x64-Setup.exe` ou a versão portátil `ContentFlow-V0-0.5.0-x64-Portable.exe`. A Browser Bridge e os plugins permanecem distribuídos separadamente nos arquivos do ecossistema.
