# ContentFlow v0.5.1

## Roteiros longos no Claude Browser Studio

- O Claude Browser Studio aceita geração simples ou uma sequência de até 32 prompts na mesma conversa.
- Outlines e quantidades de blocos passam a produzir trechos consecutivos, concatenados na ordem e com continuidade narrativa.
- A meta total de caracteres é distribuída entre as etapas e validada com tolerância configurável.
- Quando o texto fica abaixo da faixa, o plugin pode solicitar complementos antes de concluir.
- O resultado validado pode ser entregue também como arquivo Markdown gerenciado pelo ContentFlow.

## Contexto em arquivo

- Adiciona o plugin **Construtor de Arquivo de Texto**, que consolida textos, números, listas e registros em `.md` ou `.txt`.
- O arquivo pode ser conectado diretamente às portas de anexos dos Browser Studio, evitando prompts excessivamente grandes.
- O processamento é local e não envia o conteúdo a terceiros.
- ChatGPT e Claude Browser Studio normalizam anexos Markdown para uma cópia temporária `.txt` durante o upload, preservando o artifact original.

## Validação real

- Fluxo histórico executado de ponta a ponta com pesquisa no ChatGPT, dossiê anexado, oito prompts sequenciais e roteiro final no Claude.
- Meta escolhida de 17.000 caracteres; resultado final de 17.125 caracteres, com desvio de 0,74%.
- Os 11 blocos do Método foram concluídos, incluindo as três validações humanas, sem falhas remanescentes.
- Contratos e sandboxes dos três plugins aprovados, além de 138 testes dos plugins de navegador.
