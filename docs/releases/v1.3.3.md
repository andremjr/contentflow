# ContentFlow 1.3.3

- Distribuição separada: aplicativo em contentflow; plugins em plugins-contentflow; Métodos em methods-contentflow.
- Catálogo de plugins dentro do app com instalação individual e metadados de API/versão mínima corrigidos para detectar atualizações compatíveis e mostrar o indicador azul.
- Catálogo de Métodos integrado à prévia de importação existente. O catálogo inicial contém somente Gerar Imagens Flow — Assets Visuais, com sete Blocos.
- Plugins e Método publicados pelo mantenedor sob MIT. Licenças de terceiros e licença proprietária do núcleo permanecem separadas.
- Site Ecosystem conectado aos novos repositórios; Métodos antigos retirados dessa distribuição.
- Inclui a base local de execução, edição de Métodos e Browser Bridge aprovada para distribuição pelo criador nesta sessão.

## Montagem e limites

O criador determinou início do zero para os alunos e dispensou testes de versões anteriores e suites nesta publicação. Foram realizadas compilação e conferência de contratos/metadados e integridade de artefatos. Isso não comprova migração de instalações antigas ou novos cenários de execução. Não há exclusão automática de dados locais.

A montagem e a publicação são locais/diretas, sem GitHub Actions. Plugins são instalados e ativados explicitamente; contas e perfis precisam de configuração local. Métodos não substituem personalizações automaticamente.
