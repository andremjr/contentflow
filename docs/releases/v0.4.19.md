# ContentFlow v0.4.19

## ContentFlow Browser Bridge 0.3.0

- Migra a entrega física das ações de interface para o Chrome DevTools Protocol pela API nativa `chrome.debugger`.
- Mantém inalterado o contrato externo v2 usado pelos plugins de navegador.
- Localiza controles com scripts efêmeros via `Runtime.evaluate` e calcula coordenadas de viewport e documento.
- Executa cliques reais do protocolo com `Input.dispatchMouseEvent` e entrada de texto com `Input.dispatchKeyEvent` e `Input.insertText`.
- Serializa comandos por aba e garante `chrome.debugger.detach` ao terminar cada comando.
- Centraliza seleção, cancelamento, execução e idempotência no Service Worker. O Content Script permanece somente como sinal de ativação do worker.
- Preserva as allowlists compartilhadas de ChatGPT, Claude, Gemini, Google Flow, Grok e Meta AI.

## Permissão da extensão

A versão 0.3.0 adiciona a permissão `debugger`. Perfis que já usam a extensão sem compactação devem recarregá-la em `chrome://extensions` e aceitar a nova permissão quando solicitado. Não é necessário remover a extensão quando ela já aponta para a pasta atualizada.

## Validação

- Teste real concluído pelo usuário em um perfil dedicado: o Chrome exibiu o aviso de depuração, o plugin preencheu o texto, enviou a ação e coletou a resposta esperada.
- Teste automatizado de 301 comandos, cobrindo idempotência, cálculo de alvo, `mousePressed`, `mouseReleased`, seleção por teclado, `Input.insertText`, cancelamento e correspondência entre `attach` e `detach`.
- `npm run check` completo, incluindo lint, typecheck, testes do núcleo, plugins, sandbox, updater, limites de distribuição e builds cliente/SSR.
