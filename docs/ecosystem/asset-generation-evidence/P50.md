# P50 — Caracterizar Meta e fixar a fronteira com Vibes

Data: 2026-09-25

## Resultado

As três capabilities existentes do `local.contentflow.meta-ai-browser-studio` foram congeladas por fixture e teste sem alteração do handler ou do manifesto. A fronteira agora fica explícita: o plugin Meta opera apenas em `meta.ai`/`www.meta.ai`; a capability antiga `generate-video-in-browser` usa a rota histórica `https://www.meta.ai/vibes`, enquanto `https://vibes.ai` pertence ao pacote separado `local.contentflow.vibes-browser-studio`.

## Baseline antes da alteração

- `node ecosystem/plugins/reference/meta-ai-browser-studio/test.mjs`: 22/22 testes passaram.
- `npm run plugin:kit -- check ./ecosystem/plugins/reference/meta-ai-browser-studio`: compatível.
- `npm run plugin:kit -- test-contract ./ecosystem/plugins/reference/meta-ai-browser-studio`: passou.
- `npm run plugin:kit -- test-sandbox ./ecosystem/plugins/reference/meta-ai-browser-studio`: passou.
- `npm run test:browser-plugins`: 233/233 testes passaram.

## Contrato congelado

| Capability | Entradas | Saídas | Rota Meta |
| --- | --- | --- | --- |
| `generate-text-in-browser` | `content`, `attachments` | `result`, `parts` | `https://www.meta.ai/` |
| `generate-image-in-browser` | `prompt`, `references` | `image`, `description` | `https://www.meta.ai/create` |
| `generate-video-in-browser` | `prompt`, `references` | `video`, `description` | `https://www.meta.ai/vibes` |

A fixture `fixtures/p50-meta-vibes-boundary.json` registra IDs, portas, bindings, hosts e rotas. O teste falha se uma capability for removida/renomeada, se portas mudarem ou se o handler Meta passar a navegar para `https://vibes.ai`.

## Vídeo legado

`generate-video-in-browser` continua com saída singular obrigatória `video`, aceita referências `image`, `video`, `file` e `files`, produz `video` + `textarea`, navega para `www.meta.ai/vibes`, captura o vídeo novo da página e materializa o artifact local. Nenhum redirecionamento para o plugin Vibes standalone foi introduzido.

## Origens e mídia

- origens de automação Meta: `https://meta.ai` e `https://www.meta.ai`;
- hosts de rede declarados: `meta.ai`, `www.meta.ai`, `facebook.com`, `*.fbcdn.net`;
- origem standalone separada: `https://vibes.ai`;
- o README deixa de descrever o Meta como implementação do Vibes standalone e documenta a rota legada explicitamente.
