### Incrementalidade

Cada imagem materializada publica imediatamente:

```json
{
  "key": "generation",
  "variantKey": "image:0",
  "outputPort": "images",
  "state": "completed",
  "input": "<prompt que originou o grupo>",
  "value": "<StoredFile promovido pelo núcleo>"
}
```

O índice da variante é local e estável dentro da tentativa. O plugin não cria IDs universais. Quando P32 adicionar lote, o núcleo acrescentará `request.batch.itemId` à identidade sem exigir mudança nessa chave local.

O snapshot parcial contém a coleção acumulada e os artifacts já materializados. Assim, uma segunda variante não substitui a primeira e a galeria pode aparecer antes do retorno final.

### Validação de mídia

- O `Content-Type` da resposta autenticada deixou de ter fallback artificial para PNG.
- Os bytes são decodificados somente de base64 canônico e limitados a 50 MiB.
- A assinatura real é conferida para PNG, JPEG ou WebP.
- MIME ausente ou `application/octet-stream` usa o tipo detectado; um MIME de imagem divergente é rejeitado.
- Nome, extensão, `StoredFile` e artifact usam o MIME detectado, não o header não confiável.
