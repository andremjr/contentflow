## Ambiente E2E decidido pelo mantenedor

Os perfis dedicados que poderão ser usados quando um pacote exigir E2E são `flow-e2e`, `meta-e2e` e `chatgpt-e2e`. Os projetos descartáveis correspondentes são `CF Flow Teste`, `CF Meta Teste` e `CF ChatGPT Teste`. O Free Stock usará somente chaves de teste já cadastradas no cofre; este relatório não registra nem solicita seus valores.

Não existe teto numérico de gerações ou valor monetário. A política aprovada é: executar somente os cenários mínimos necessários para validar o pacote; respeitar a cota, o plano e os limites efetivamente informados pelo provedor; nunca tentar inferir, ampliar ou contornar crédito, rate limit, CAPTCHA, bloqueio ou upgrade. Diante de erro, o plugin deve aplicar a recuperação já declarada: avançar somente para o próximo perfil dedicado configurado quando o erro for elegível, ou pausar a produção para retomada posterior quando exigir intervenção humana ou quando a cota não permitir continuar. Nenhuma tentativa E2E deve supor saldo disponível.
