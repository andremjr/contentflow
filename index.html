COMO UM MÉTODO É MONTADO

Todo passo faz uma destas quatro coisas.

B01

BUSCAR

Encontrar algo que ainda falta: dados, referências ou arquivos.

Exemplo: pesquisar vídeos, comentários e tendências.
E02

ESCOLHER

Pegar uma opção que já existe na sua Biblioteca Estratégica.

Exemplo: escolher uma estrutura de título do canal.
C03

CRIAR

Produzir algo novo: texto, imagem, áudio, vídeo ou dado.

Exemplo: criar dez títulos usando a estrutura escolhida.
V04

VALIDAR

Olhar o resultado e decidir se ele pode seguir adiante.

Exemplo: aprovar um título ou pedir outra tentativa.

PLUGIN NÃO É A MESMA COISA QUE CAPACIDADE

O plugin é a caixa.
A capacidade é o que existe dentro dela.

Um plugin pode, por exemplo, gerar imagens, remover fundos e montar thumbnails. Cada uma dessas ações é uma capacidade. Ela informa o que precisa receber e o que consegue entregar.

OS 5 TIPOS DE TRABALHO

Clique em uma área e veja o que um plugin pode fazer.

Um mesmo plugin pode trabalhar com uma ou várias áreas. O ContentFlow usa essa informação para encontrar a ferramenta certa para cada passo.

ENTÃO, QUAL É A DIFERENÇA?

Ferramentas produzem.
O ContentFlow organiza o jeito de produzir.

Por isso, uma IA nova não torna o ContentFlow desnecessário. Ela apenas oferece uma opção melhor para fazer algum passo.

DÚVIDAS DE QUEM ESTÁ COMEÇANDO

Sem complicar o que é simples.

Ele faz um vídeo inteiro sozinho?+

Pode fazer várias partes automaticamente, mas não precisa fazer tudo. Você decide em quais passos quer participar e quais serão entregues a uma IA ou ao Código.

Por que não usar apenas uma sequência de prompts?+

Porque prompts guardam instruções, mas não organizam sozinhos todo o trabalho. Um Método também registra a ordem, os arquivos necessários, quem faz cada passo, o que deve sair e quando você precisa aprovar.

Ele substitui ChatGPT, Claude, geradores e editores?+

Não. Ele organiza quando e como cada uma dessas ferramentas será usada. Elas fazem o trabalho; o ContentFlow guarda o seu jeito de trabalhar.

O plugin decide como meu vídeo será feito?+

Não. Você monta o Método. O plugin apenas oferece ações que podem ser usadas em alguns passos.

Preciso saber programar?+

Não para instalar o aplicativo, organizar projetos e montar Métodos. Programação só é necessária se você quiser desenvolver novas capacidades de plugin.

O ContentFlow é open source?+

O código do núcleo é público para transparência, avaliação e contribuições, mas usa uma licença proprietária source-available. Você pode baixar e operar o aplicativo; clones, reskins e redistribuições do núcleo não são autorizados pela licença pública.
